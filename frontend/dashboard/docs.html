🛡️ ShieldID REST API Specification

Enterprise-grade automated identity verification, AI forensic tampering detection, biometric face matching, and instant DigiLocker KYC for Indian identity documents (Passport, Aadhaar, PAN, Driving License, Voter ID).

● OpenAPI 3.1.0 Base URL: /api/v1 Local Dev: http://localhost:8080 Dashboard: http://127.0.0.1:5173

1. System & Health Check Endpoints

GET / Service status and root info

Returns high-level service status, platform version, and links to interactive documentation.

Response (200 OK)
{
  "service": "ShieldID",
  "version": "1.0.0",
  "status": "operational",
  "docs": "/api/docs"
}
GET /health Liveness & readiness probe

Health check probe used by Docker, Kubernetes, and load balancers.

Response (200 OK)
{
  "status": "healthy"
}

2. Document Verification Module

POST /api/v1/verify/document Submit document & optional selfie

Upload an identity document for OCR text extraction, tampering analysis, and facial matching.

Request Form Data
FieldTypeRequiredDescription
documentFile (Binary)YesIdentity document image/PDF (JPEG, PNG, PDF up to 10MB)
selfieFile (Binary)NoLive selfie photo for facial biometric match
Response (200 OK)
{
  "status": "verified",
  "risk_score": 15,
  "document_type": "passport",
  "name": "Rahul Sharma",
  "recommendation": "APPROVE"
}
GET /api/v1/verify/status/{verification_id} Poll verification status

Poll processing progress for asynchronous verification workflows.

Response (200 OK)
{
  "status": "completed",
  "verification_id": "SHIELD-VER-2026-009871"
}

3. Instant KYC & Fraud Reporting Module

POST /api/v1/kyc/instant Initiate DigiLocker KYC flow

Generates an instant KYC verification session with QR code and DigiLocker redirect.

Response (200 OK)
{
  "status": "pending",
  "kyc_token": "SHIELD-KYC-2026-001234",
  "qr_code": "https://api.qrserver.com/v1/create-qr-code/?data=SHIELD-KYC-2026-001234",
  "digilocker_redirect": "https://digilocker.gov.in/"
}
POST /api/v1/report/fake Submit fraud report

Submit fraudulent document details for automated cyber crime routing and police FIR dispatch.

Response (200 OK)
{
  "report_id": "REP-2026-0089",
  "status": "dispatched",
  "fir_number": "FIR-DL-2026-4402"
}
